# Benchmark results, 2026-10-19

DbToRestAPI 1.7.17 against a hand-written Minimal API running the same SQL ([README](../README.md)).

- Machine: AMD Ryzen 7 5800H with Radeon Graphics, 16 logical CPUs, 29 GB, Microsoft Windows 10.0.26300.
- Runtime: Microsoft.AspNetCore.App 10.0.13. Each server pinned to logical CPU 2 with `DOTNET_PROCESSOR_COUNT=1`; the load generator on the other CPUs, the database wherever its own service runs.
- SQL Server: SQL Server 16.0.1210.3 Developer Edition (64-bit), on the same machine.
- 10000 contacts. Each run: 3 s warmup, then 10 s measured, from 1 and from 32 connections.
- CPU per request is the server process's CPU time divided by the requests it answered: what a request costs on a 1 vCPU machine.
